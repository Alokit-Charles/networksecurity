How a prediction gets made

Four stages, run end-to-end every time you hit Train.

01

Ingest

Pulls labeled URL records from MongoDB and splits them into train / test sets.

02

Validate

Checks the data against the expected schema and screens for feature drift.

03

Transform

Imputes missing values and prepares the 30 structural features for training.

04

Train

Fits six candidate models, keeps the best performer, logs it to MLflow.

01 — Model

Runs the full ingestion-to-training pipeline against the current data in MongoDB and saves a fresh model for prediction. Takes a minute or two, depending on data volume.
